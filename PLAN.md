# Plan

Fourteen-day arc for Steadyline. Every milestone has acceptance criteria checkable by a test or command. `bash check.sh` must pass at the end of each day.

| Day | Milestone                                                                             | Acceptance criteria                                                                                                                                                                                                                                                                            | Status |
| --- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| 1   | Scaffold, FHIR domain model, synthetic patient, glucose metrics, landing + demo shell | Vite/TS strict/Vitest/ESLint/Prettier/Playwright and Pages workflow work; every generated resource validates; generator output is byte-identical per seed; TIR/TAR/TBR/GMI/CV tests match published formulas and boundaries; landing and demo render at 360 px with no horizontal scroll (e2e) | [x]    |
| 2   | Encrypted local storage                                                               | AES-GCM + PBKDF2/Argon-style KDF via WebCrypto, tests for round trip, wrong passphrase rejection, tamper detection; IndexedDB repository with typed queries; lock/unlock UI; data never stored in plaintext (test inspects raw DB)                                                             | [ ]    |
| 3   | Onboarding and fast logging                                                           | Onboarding picks conditions and creates Condition resources; quick-add with keyboard shortcuts logs a vital in under 5 s (e2e measures keystrokes); symptoms 0-10 with body location; meds taken/missed; sleep, mood, food, activity, triggers, notes                                          | [ ]    |
| 4   | Condition templates and BP panel                                                      | Per-condition quick-add templates; BP averages and ACC/AHA 2017 category with table-driven tests on every threshold; BP chart with data table                                                                                                                                                  | [ ]    |
| 5   | CSV importers                                                                         | Dexcom/Libre-style and Google Fit/Health Connect CSV streaming parsers with fixtures, malformed-row reporting, dedupe on re-import, tests for 100k-row input in constant memory                                                                                                                | [ ]    |
| 6   | Apple Health importer                                                                 | Streaming SAX-style `export.xml` parser (Web Streams) mapping HK types to LOINC; fixture tests; progress UI and cancel                                                                                                                                                                         | [ ]    |
| 7   | CGM dashboard                                                                         | AGP percentile chart (5/25/50/75/95), daily overlays; 1 year of minute-level data renders under 1 s (benchmark test in CI)                                                                                                                                                                     | [ ]    |
| 8   | Adherence, symptoms and flares                                                        | PDC with tests on edge cases; symptom heatmap calendar; flare timeline detection with documented rule                                                                                                                                                                                          | [ ]    |
| 9   | Insights engine I                                                                     | Spearman with tie handling, permutation test (seeded), Benjamini-Hochberg; tests against known values and planted correlations in the simulator                                                                                                                                                | [ ]    |
| 10  | Insights engine II                                                                    | Lagged effects (0-3 days), anomaly detection on vitals (robust z / MAD), missed-dose patterns; every insight shows n and "association is not causation"                                                                                                                                        | [ ]    |
| 11  | Medication schedule and PWA                                                           | Schedule editor, refill countdown, Notification API reminders, service worker offline (e2e offline load), installable manifest                                                                                                                                                                 | [ ]    |
| 12  | Doctor visit report                                                                   | 30/90-day printable report with charts, adherence, flagged readings, patient questions; print stylesheet; PDF via print                                                                                                                                                                        | [ ]    |
| 13  | Caregiver mode and FHIR Bundle I/O                                                    | Encrypted export/import with passphrase; FHIR Bundle round trip; merge conflict rules documented and tested                                                                                                                                                                                    | [ ]    |
| 14  | Polish and release                                                                    | WCAG AA audit with axe in e2e, screen-reader chart tables everywhere, light/dark, 360 px, perf budget, screenshots, docs, v1.0                                                                                                                                                                 | [ ]    |

## Stretch

- mmol/L display preference, multi-profile support, Health Connect JSON, FHIR `Observation` CGM export as `Observation` series.
